# Stranger Things Web Projesi 🎬

Bu proje, Stranger Things dizisinin temel tanıtımını yapan, HTML5 ve CSS3 kullanılarak hazırlanmış bir web sitesidir.

## Proje Detayları
* **Tema:** Stranger Things
* **Teknolojiler:** HTML, CSS
* **Hedef:** Flexbox ve temel responsive tasarım prensiplerini uygulamak.

## Kurulum ve Çalıştırma
1.  Projeyi indirin (clone).
2.  `index.html` dosyasını tarayıcınızda açarak projeyi görüntüleyebilirsiniz.
